# Meu Planner Pessoal

Projeto totalmente separado do **Sistema RH PRO**.

## Funções iniciais
- Dashboard com resumo do dia
- Agenda de compromissos
- Tarefas com status de pendente ou concluída
- Cadastro de pessoas importantes
- Anotações pessoais
- Salvamento dos dados no navegador

A estrutura inicial do aplicativo está organizada neste repositório independente para que nenhuma alteração interfira no RH PRO.
